為什麼要做相似度檢查？

Purpose

常見的寫作問題

  • 文字與他人高度相似
  • 過度引用他人文字
  • 引用了卻沒有標註出處

正確的用法

  • 用報告檢視自己的文章
  • 修正引註、補上出處、改寫語句
  • 培養正確的學術寫作觀念
注意相似度百分比只是參考，不能直接拿來判定有沒有抄襲。

這個系統的特色

Features

  • 可以多次上傳、反覆比對

及時取得報告

  • 上傳後等待比對完成
  • 約 15–30 分鐘就能查看報告

提升原創性

  • 看出哪些段落與外部來源相似
  • 協助你修正寫法

第一步：請老師把你加入課程

Get enrolled
  1. 向指導教授或修課教師申請加入課程
  2. 老師把你加入課程後，你的信箱會收到系統歡迎信
  3. 加入不同課程，每次都會收到歡迎信
  4. 已有帳號的話，可直接登入查看新課程
小提醒歡迎信上的按鈕若寫「即刻登入」，表示你已有帳號，用之前的帳號密碼登入即可，不用重新開通。

帳號啟用（1）：輸入信箱與姓氏

Activate your account
  1. 點選歡迎信中的啟用連結
  2. 輸入收信的信箱
  3. 姓氏欄只填「姓」，不要填全名（歡迎信左上角有顯示）
  4. 按「下一步」
小提醒若出現找不到帳號的紅色提示，請再檢查信箱與姓氏是否輸入正確。

帳號啟用（2）：到信箱點連結

Check your inbox
  1. 系統會再寄一封「建立密碼」的通知信
  2. 在信中點選設定密碼的連結
  3. 連結只在一段時間內有效，請盡快完成

帳號啟用（3）：建立密碼

Create a password
  1. 至少 12 個字元
  2. 至少包含一個數字
  3. 同時包含大寫與小寫字母
  4. 至少包含一個特殊符號
  5. 輸入兩次相同的密碼，按「建立密碼」
注意請設定與學校信箱、入口網站、電子資源系統「不同」的密碼；這個系統的密碼不會與它們同步，不同密碼比較安全。

帳號啟用（4）：完成設定

Finish setup
  1. 看到「帳戶設定完成」後，按信中的連結回到登入畫面
  2. 在選單中選一個「秘密安全問題」，並填入只有你知道的答案
  3. 閱讀並同意使用條款後，按「下一步」
  4. 完成後就能登入使用
小提醒請記住秘密問題的答案，之後重設密碼會用到。

沒收到啟用通知信怎麼辦？

No email?

  • 檢查垃圾郵件匣
  • 改用「重設密碼」的方式開通帳號
  • 如果還是不行，請聯絡幫你建立帳號的老師或管理者

哪些檔案可以上傳？

Supported files
項目規定
檔案格式Word、Excel、PowerPoint、WordPerfect、PostScript、HTML、RTF、OpenOffice（ODT）、Hangul（HWP）、Google Docs、純文字
PDF 的限制不能加密；文字必須可選取；不能是 Mac 直接轉出的 PDF
檔案大小小於 100 MB、不超過 800 頁
字數至少 20 字

重新繳交前，先看這些規則

Resubmitting
  1. 新文稿與新報告會覆蓋舊檔案
  2. 每個上傳區最多可重新上傳 50 次
  3. 同一個上傳區超過 3 次後，之後每一次報告都會停在「處理中」，要等 24 小時才會產生新報告
  4. 建議預留 1–2 個作業夾，留作緊急時使用
注意不要在截止前一刻才開始上傳；先自我檢查，預留修改時間。

  2. 檔案越大、頁數越多，等待越久
  3. 請耐心等 15–30 分鐘，再重新登入查看報告

先想清楚，再使用「篩選與排除」

Before you filter
  1. 可排除的三類：引文、參考書目、小型來源
  2. 你用學生帳號篩選時，相似度百分比只會「暫時」改變；重新登入就會恢復成原本的結果
  3. 如果由指導教師從教師帳號代為篩選，結果則會保留
  4. 使用前，請先參考學校或系所的規範，或與指導教師討論
注意排除是為了排除不合理的相似，不是為了把百分比變漂亮。

排除引文

Exclude quotes
  1. 開啟「篩選條件與設定」
  2. 勾選「排除引用資料」，再按「套用變更」
  3. 系統支援排除用引號框起來的文字，例如 “…” 「…」 『…』 ‘…’
  4. 不支援用括號（…）框起來的內容

相似度要低於多少才算「適切」？

What is acceptable?
  • 沒有一個適用於所有人的標準數字
  • 不同學科、不同文章類型，合理的相似比例不同
  • 系統只比較你的文章與資料庫內容（網頁、期刊、學生文稿）有多相似，它不判定抄襲
補充重點是為什麼相似、引用是否正確，不是單看數字。

同樣是 14%，內容卻可能不同

Same total, different story

百分比低，不代表沒問題

Low similarity

可能的情況

  • 兩篇文章的總相似度一樣，內容卻可能很不同
  • 有的是零星小段落相似，有的是整段照搬

提醒

  • 只看總百分比容易誤判
  • 還要看相似是從哪些來源、哪些段落來的
  • 需在合理範圍內正確引用他人著作

百分比高，不代表一定抄襲

High similarity

可能不是抄襲的情況

  • 專有名詞、常用詞句、目錄格式、標準流程、參考文獻
  • 按學術規範引用他人文字，例如法條的原文
  • 比對到自己先前的文章，包含發表過或曾經存入系統的作業草稿
補充不同章節的合理程度也不同，例如「結論」比「研究方法」更需要有原創性。

相似度偏高時，可以這樣做

What to do
  • 檢查引註格式是否正確、出處是否齊全
  • 用改寫、摘要等寫作技巧，調整文字內容
  • 無法改寫的內容，請與指導教師討論
  • 必要時使用「篩選與排除」，或請老師用教師帳號排除特定來源
小提醒有疑問可參考學術倫理教育資源，例如臺灣學術倫理教育資源中心網站（ethics.moe.edu.tw），或欲投稿期刊出版社的官方說明。

很久沒出現報告？可能原因與解決

No report yet?
可能原因解決方法
檔案很大，或超過百頁系統需要較長時間，建議 1–2 小時後再查看
同一作業上傳超過 3 次每次都要等 24 小時才會產生新報告
伺服器逾時，超過 24 小時仍無報告另存成 PDF 重新上傳；仍失敗再回報
Word 內嵌互動圖表或 SmartArt把圖表轉成圖片，或整份轉成 PDF 再上傳
Word 開著追蹤修訂先「接受所有變更」，再轉成 PDF 重新比對
補充也可能是老師的作業設定造成：請老師確認有開啟「產生相似度報告」，並允許學生查看報告。

文章被誤存入資料庫，一直比對到自己？

Accidentally stored?
  • 請老師用報告中的「排除特定來源」功能（只有教師帳號能用），排除與你自己的文章相似的來源
  • 再向學校的 Turnitin 管理者申請，從資料庫刪除誤存的文稿
  • 刪除後，重新產生一份新報告，確認是否已解除

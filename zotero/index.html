為什麼要用書目管理工具？

Why a reference manager?
摘要前言研究方法結果與討論結論與建議參考文獻
  • 報告、期刊論文、學位論文，大多遵循固定的結構
  • 內文要有「引註」（citation），說明資料出自哪裡
  • 文末要有「參考文獻」（bibliography），列出完整出處
  • 兩者必須一一對應、格式一致——手動維護很容易出錯
  • 把繁瑣的整理與排版交給工具，時間才能花在思考與寫作

同一篇文獻，不同格式

The same paper, three styles
作者年份篇名期刊名卷期與頁碼DOI
APA

Kahneman, D., & Tversky, A. (1979). Prospect theory: An analysis of decision under risk. Econometrica, 47(2), 263–291. https://doi.org/10.2307/1914185

MLA

Kahneman, Daniel, and Amos Tversky. “Prospect Theory: An Analysis of Decision under Risk.” Econometrica, vol. 47, no. 2, 1979, pp. 263–91. https://doi.org/10.2307/1914185

Chicago

Kahneman, Daniel, and Amos Tversky. 1979. “Prospect Theory: An Analysis of Decision under Risk.” Econometrica 47 (2): 263–91. https://doi.org/10.2307/1914185

小提醒同樣的六項資料，順序、標點、斜體與縮寫方式都不同。資料只要輸入一次，Zotero 就能一鍵轉換成上百種格式。

Zotero 是什麼？

What is Zotero?
  • 由美國喬治梅森大學團隊於 2006 年開發
  • 一開始是 Firefox 外掛，現在是獨立程式，並支援 Chrome、Edge、Safari、Firefox 外掛
  • 開放原始碼、免費使用，使用者社群活躍
  • 特色：跟瀏覽器緊密整合，看到文獻就能直接存
  • 適合學術寫作的原因
    • 書目資料可自動辨識與補齊（DOI、ISBN 等）
    • 社群提供各式擴充功能
    • 跨平台，資料可在多部裝置同步
補充Zotero 持續更新，安裝時請直接到官網下載目前的最新版。

Zotero 的核心功能

Key features

1. 書目管理

  • 自動抓取網頁的標題、作者、DOI、PDF
  • 輸入 DOI／ISBN／PMID 快速建檔
  • 用標籤、註解、找全文整理資料

2. 引用與格式

  • 與 Word、Google Docs 整合
  • 支援 9,500 種以上引用格式
  • 可快速複製引註與參考文獻

3. 多人協作

  • 建立群組文獻庫
  • 邀請同學、組員共同編輯
  • 搜尋並加入公開群組

4. 線上同步

  • 帳號同步到雲端
  • 網頁版隨處可用
  • 多部裝置同一份資料

EndNote 匯入的限制

Limitations
  • 若 EndNote 書目夾帶圖檔，圖檔無法跟著 PDF 匯入，需自行另存後再補到 Zotero
  • 可在 Zotero 用關鍵字 .jpg 或 no corresponding zotero field 找出沒匯入的欄位資訊
  • EndNote 裡設定的 Groups，無法以整個文獻庫匯出的方式保留
  • 想保留分組：以每個 Group 為單位，全選書目、勾選 Export Selected References，逐組匯出成 .xml
注意搬家前先留一份 EndNote 原始資料備份，最保險。

備份與空間管理

Backup & storage
  • 書目、筆記、標籤同步到 Zotero，不計入雲端空間
  • 免費帳號有 300 MB 空間，用來放 PDF、圖片等附件
  • 空間不夠時，可以
    • 升級 Zotero 的付費儲存方案
    • 改用 WebDAV 連接自己的雲端空間（要留意穩定性）
    • 把附件放在自己的雲端硬碟，只同步書目
小提醒不論用哪種方式，都建議定期把 Zotero 資料夾另外備份一份。

建立群組文獻庫

Create a group

三種群組類型

Group types
類型誰能看怎麼加入
公開、開放加入所有人任何人都能直接加入
公開、需申請所有人要申請或受邀才能加入
私人只有成員要受邀才能加入
小提醒課堂小組報告通常選「私人」；想分享文獻清單給大家，才選公開。

讓桌面版看見新群組

Sync the group
回到桌面版 Zotero，按右上角同步按鈕，左側就會出現新的群組文獻庫。
注意如果刪除過同名群組又想重建，請先到群組文獻庫的垃圾桶徹底刪除舊的，否則會因名稱重複而出錯。

邀請成員共同編輯

Invite members
  • 只有群組擁有者能邀請；對方必須有 Zotero 帳號
  • 步驟：網頁版 Zotero → 該群組 → Manage Members
  • 點 Send More Invitations，在 Invite Members 欄位輸入帳號或 Email（用逗號或換行分隔）
  • 對方會收到 Email，也能在網頁版的 Inbox 看到邀請
  • 點邀請連結了解群組後，按 Join 加入

成員角色與權限

Roles
角色能做什麼
擁有者 Owner變更成員角色、刪除群組、轉移擁有權
管理者 Admin同擁有者，但不能刪除群組、不能轉移擁有權
成員 Member一般成員，權限由文獻庫設定決定
補充在網頁版「Groups → 該群組 → Manage Members」下拉選單調整角色，按 Update Roles 儲存。

文獻庫的公開與編輯設定

Library settings

閱覽權限

  • 線上所有人
  • 僅群組成員

文獻庫編輯權限

  • 群組所有成員
  • 僅管理者

檔案編輯權限

  • 所有成員
  • 僅管理者
  • 公開群組沒有檔案儲存空間
補充路徑：網頁版 Zotero → Groups → 群組名稱 → Manage Library，由管理者設定。
